# Welcome

This is a demo wiki built with **wikibuilder** — an open-source, zero-dependency
static wiki generator.

Everything you see here was generated from plain Markdown files in the
`content/` directory. To get started, read the [[Getting Started]] page, or
learn how the [[Syntax]] works.

## Features

- Plain Markdown in, a self-contained static site out
- `[[wiki links]]` between pages, with automatic **backlinks**
- Client-side full-text search — no server required
- Light & dark themes out of the box
- No build dependencies: just Python 3.9+
